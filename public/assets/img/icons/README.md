# Age of Pixel game icons

Place transparent PNG files in this folder using these exact lowercase names:

- `worker.png`
- `barbarian.png`
- `archer.png`
- `spearman.png`
- `townhall.png`
- `barracks.png`
- `gold-mine.png`
- `village.png`
- `fortress.png`
- `arrow.png` — projectile fired by archers
- `build.png` — action icon shown when a worker is selected

Recommended source size: 128x128 or 256x256 pixels, square canvas, transparent background, and consistent viewing angle. The game scales them down with crisp pixel rendering.
